# Patient Encounter System (FastAPI)

A production-grade backend system built using **FastAPI**, **SQLAlchemy**, and **Poetry** to manage patients, doctors, and appointment scheduling with strict business rules, high test coverage, and CI/CD support.

---

## 🚀 Features

- Patient management (create, fetch)
- Doctor management (create, fetch)
- Appointment scheduling
- Overlap prevention for doctor appointments
- Timezone-aware scheduling
- Clean service-layer architecture
- SQLite-based isolated testing
- More than 90% test coverage
- CI/CD using GitHub Actions

---

## 🛠 Tech Stack

- Python 3.10
- FastAPI
- SQLAlchemy 2.x
- MySQL (production)
- SQLite (testing)
- Poetry
- Pytest + Coverage
- GitHub Actions
